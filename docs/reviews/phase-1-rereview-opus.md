## 4. What is sound

- **Head-CAS executor.** Every attempt pins X; dedupe, reads and the commit parent all use X. Failures while creating objects are `StoreUnavailable` (nothing durable). Only the ref PATCH can have an unknown outcome, and it re-dedupes. A stale `head()` read cannot cause harm, because a commit parented on a stale X is rejected. The ABA hole is closed on all three adapters.
- **Exact Undo via parent bytes.** It is sound under the blob-equality condition: `replayOnParent` proves `complete(T^) = T:path = file@X`, so writing `T^:path` is the exact inverse even when the file went through edits that were later reverted. Idempotent replay of the Undo on `U^` re-derives the same bytes.
- **Kernel.** The semantic inverse now refuses adoption and checks every other block. Completion refuses a Done section that ends inside an unclosed fence. The fuzz run found no byte changes outside the span and no BOM or EOL damage.
- **Queue.** IndexedDB is the source of truth inside the Web Lock. `everSent` is sticky and written before the request. A lease plus `claimId` makes settlement ownership explicit. A receipt always settles, even when another tab already did. A dependent is released only on a refusal known not to have applied. The account is re-checked synchronously before the send and again on the server.
- **Worker.** The JWT claims and lifetime are enforced. The server binds the account. Config fails closed. The runtime log allowlist and the production wiring are now guarded by tests that fail when the guard breaks.
