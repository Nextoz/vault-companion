### Test adequacy and scope limits

- A3 goldens compare actual original bytes, so they are meaningful, but miss the small reversed-section/empty-Done ambiguity in A1. The production acceptance condition needing a stronger oracle is `mutations.ts:173`.
- A25's pinned-X test is meaningful against reading mutable HEAD, but it only exercises a monotonic content change. It cannot establish the stronger exactly-once claim against an inverse that restores the old SHA (A2).
- Sequential collision tests correctly exercise `noteFileName` case folding. They do not guard the namespace between `commands.ts:129` and the create PUT (A4).
- Queue dependency/account tests exercise the single-instance checks, but do not share one durable store across independent senders or change the session during `queue.ts:262` (A3/A7).
- `auth.test.ts:29` always adds expiration. Existing expired-token tests remain meaningful, but cannot detect acceptance of absent expiry (A6).
- `paths.test.ts:50` explicitly describes the older denylist behavior and checks only Journal, Health and Projects. A test of `canReadLinkedNote` must reject a fourth, nonallowlisted root (A8).
- The only deliberately broken production guard run here was the temp log mutant. No claim is made that all other guards were mutation-tested in this independent review.
- No Cloudflare deployment, live GitHub request, real-phone/browser end-to-end run, or Windows checkout of colliding case variants was performed. Production behavior beyond recorded G1 evidence is not certified. The schema-valid current command paths limit the exposure of A8; the missing linked-note endpoint is not portrayed as a live read exploit.
- The older A8 acceptance wording says append at the end; ADR-0010 and current vault-contract §4.4 supersede it. Top-of-Open capture is therefore not counted as an implementation defect.

## What is sound

- The decoder uses fatal UTF-8 decoding with BOM retention, and the kernel's line model preserves normal LF/CRLF/BOM bytes. Mixed EOL, lone CR, malformed Unicode and conflict-marker refusal have substantive tests. The exact inverse defect does not negate those independent guards.
- Locator replay uses exact text and refuses changed-blob twins rather than choosing arbitrarily. Recurrence, on-completion and duplicate trailing fields are explicitly refused. Capture checks that its insertion does not reinterpret the rest of the document and refuses an indented first insertion boundary.
- Pinning reads and dedupe to one immutable X prevents the tested ordinary lost-response/dedupe/read race. Unknown dedupe windows refuse writes. Payload hashing covers the raw validated request, and Undo checks its target against commit evidence before re-deriving the completion effect. These are useful protections despite the ABA hole.
- The GitHub adapter maps recorded 409 branch/ref races to replanning and treats transport failures/5xx after PUT as potentially applied. Sequential same-path creates have a final create-without-SHA guard. The disposable-Git suite checks real blob SHA/CAS/trailer behavior rather than relying only on a mock.
- JWT signature, issuer, audience, algorithm and email checks are present; the tested bad-signature/wrong-issuer/wrong-audience/expired cases are rejected. Mutation routes enforce the custom request header and exact configured Origin; GET does not mutate. Responses carry no-store and security headers.
- In one queue instance with a stable account, commands are persisted before first send and retried using the stored body string. Session-expiry classification pauses sending, and transient failures retain the item. Those single-instance guarantees should be preserved while adding cross-tab/session coordination.
- The existing HTTP logging path hashes note paths and currently passes the sentinel checks. A10 identifies an unguarded regression route, not an observed current disclosure.

## Verdict

**BLOCK.** The existing green suite does not establish the Phase 1 safety gate. Exact Undo can commit the wrong task location, an ABA sequence can apply one operation twice and defeat a successful inverse, and a second tab can cause an Undo to be silently discarded. Fix these and the High findings, add the concrete regressions above, and rerun the gate before treating the kernel/retry/queue boundary as safe for live-vault use.
